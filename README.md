# The Poster for a Place That Isn't There

A vintage travel poster for the fictional place VELMARA — THE GLOWING BAY. The program (PIL, Python 3.13) draws one 768×1024 poster to `/output/entry.png`: a giant glowing nautilus shell (true logarithmic spiral) over a teal bay at dusk, with a full moon, stilt houses, lanterns, and sailboats.

## Run

```bash
python3 main.py
```
